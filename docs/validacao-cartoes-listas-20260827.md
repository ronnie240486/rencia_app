# Validação visual — cartões e listas adicionais

- A lista de usuários no celular apresenta cartões com quantidade de playlists, nível, valor, aplicativo, datas, status e ações em sequência segura.
- A primeira lista gravada diretamente no cadastro é incluída na quantidade de playlists do cartão.
- O cadastro mostra a ação “Adicionar outra lista”, e após salvar o cliente oferece atalho para a tela de listas do mesmo cliente.
- A tela de listas mantém a lista principal separada das listas extras e nomeia a nova inclusão na sequência correta.
